# Corruption assessment, October 28, 2026

A fresh seed-43 campaign detected all 6,930 reference-confirmed damaged inputs:
385 in each of 18 archive/profile pairs. There were no misses or unverifiable
rarz outcomes. Each pair's 95% pointwise Wilson interval is 99.01%–100%, within
the requested ±5-percentage-point precision. All pristine inputs passed both
validators and their hashes remained unchanged.

The campaign still exited 2 (`incomplete`). Its 6,948 mutations included four
reference disagreements and six inconclusive reference results. These remain
visible even though each pair met its sampling target.

## Reference exceptions

Five inconclusive cases caused UNRAR to request a nonexistent next volume
(exit 6). One corrupted RAR5 header caused a 4 GiB dictionary request that the
reference could not satisfy under the unchanged 1,024 MiB process limit
(exit 8). rarz rejected all six with header-CRC diagnostics. They remain
excluded from the damaged-case denominator; generic tool failures are not
reclassified as damage.

All four disagreements changed the primary file header at byte offset 937 in
`rar5_m3.rar`. Independent CRC calculation confirmed header checksum damage.
UNRAR's default quick-open path accepted the cached header; repeating the same
four files with `-qo-` disabled that cache and returned checksum-error exit 3
for every case. The pristine input still passed. This resolves the four cases
as primary-header damage, not established rarz false positives. The original
campaign classifications and counts above remain unchanged.

The assessment's follow-up reference protocol disables quick-open and records
the invocation flags. A persistent regression first demonstrated zero eligible
cases for four deterministic primary-header mutations, then obtained four
confirmed detections with the corrected reference invocation. Changing the
reference protocol requires separately identified campaign results.

Complete acceptance of the reference change passed 465 unit tests, all CLI
suites including the six historical/new disagreement replays, and the full
pristine/two-mutation v70 gate. Runtime cgroup peak was 11,838,328,832 bytes.
